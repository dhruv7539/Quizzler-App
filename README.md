# 🧠 Quiz App - Python GUI

This is a **Quiz Application** built in Python with a graphical user interface (GUI). It reads quiz questions from a data source, presents them interactively, and tracks the user's score.

## 🚀 Features
- Interactive **Graphical User Interface (GUI)**.
- Multiple-choice quiz with **real-time scoring**.
- Retrieves questions dynamically from `data.py`.
- Tracks **user progress** and displays results.
- Built using **Python, Tkinter**, and **OOP principles**.

## 📂 Project Structure
```python
Quiz-App/
│── README.md          # Project documentation
│── main.py            # Main script to run the quiz app
│── data.py            # Stores quiz questions and answers
│── question_model.py  # Defines the Question class
│── quiz_brain.py      # Handles quiz logic and user progress
│── ui.py              # GUI interface using Tkinter
│── images/            # Contains UI-related images
│── __pycache__/       # Compiled Python cache files
```
## 🛠️ Installation

### 1. Clone the Repository
```python
git clone https://github.com/your-username/Quiz-App.git
cd Quiz-App
```
### 2. Install Dependencies
```python
pip install -r requirements.txt
```

### 3. Run the Quiz App
```python
python main.py
```

## ⚙️ Configuration
```python
Modify `data.py` to add new questions or change existing ones.
Modify `quiz_brain.py` to customize quiz behavior.
Modify `ui.py` to change UI layout and elements.
```
